First launch on macOS?

Because Skirr is not notarized yet, macOS blocks the first start of an app downloaded through a browser. Either clear the quarantine flag once: xattr -dr com.apple.quarantine /Applications/Skirr.app, or open System Settings → Privacy & Security and click Open Anyway.
